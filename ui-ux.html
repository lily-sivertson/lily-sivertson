El3ktro-Jelly

El3ktro-Jelly is a fictional cyberpunk game idea where jellyfish power the cities that I came up with to make a logo and ui icons based on. I created these UI sheets for a class course on UI/UX, coming up with the concept for El3kro-Jelly in the process.
These sheets were created in adobe illustrator and photoshop. I spent a while before creating my final designs researching cyberpuk UIs, finding references, and analyzing color palettes. My goals with these the icons was to clearly communicate a neon cyberpunk style game, with consistent angles and bright colors. I later go on to animate a few of the ui elements, which you can see on my ArtStation.

Train Bash!

Train Bash is energetic game about bashing into other trains in space. I am working as a UI/UX designer on this game to come up with and implement assets for the UI and HUD in the game. These are some examples of temporary assets I created to showcase the abilities the player has in a simple and effective way.
